# 润物 v0.4.0

v0.4.0（内部构建号 5）把浮窗改成按区命中：标题栏与原文区负责拖动，译文区可以拖选文字并在松手时复制；同时把自定义模型的 API 密钥从钥匙串改为随模型配置保存在本机设置。支持 **Apple Silicon（arm64）、macOS 15 或更高版本**；应用身份保持「润物」与 `com.comeg.runwu`。

## 本版变化

- **浮窗按区命中**：卡片分成两个点击区——标题栏与原文区按住拖动窗口（四向不设置屏幕边界），译文区用来拖选文字。分界取原文与译文之间的分隔线，由布局实测，不写死高度比例。长译文出现滚动后，原文会随内容滚出视野，此时由标题栏负责拖动，避免留下点了没反应的原文区。
- **拖选即复制**：在译文上拖选一段，松手后把选区写入剪贴板，卡片右下角提示「已复制选中 N 字」；整段复制仍是头部复制键。两者都不重新请求服务、不写历史、不替换输入。译文按 Markdown 分块渲染，一次拖选只在一段内；浮窗不抢键盘焦点，选区高亮显示为系统的非激活浅灰色。
- **模型密钥改存本机设置**：自定义大语言模型 API 密钥不再写入钥匙串，随模型配置保存在本机偏好文件；启动、编辑模型与翻译都不再访问钥匙串，使用本地或网页服务不会被系统询问钥匙串授权。旧版本留在钥匙串里的密钥可在模型卡片中显式导入一次，导入后同样存在本机设置。

## 安装与更新

1. 从 [v0.4.0 发行页](https://github.com/cmeng-CM/Runwu/releases/tag/v0.4.0) 下载 `Runwu-0.4.0.dmg`。
2. 更新旧版时先从润物菜单栏退出应用。打开 DMG，将「润物.app」拖到「Applications」链接；已有旧版时选择替换。
3. 推出镜像，再从应用程序目录启动润物。润物目前没有自动更新。
4. 首次运行按系统提示授予「辅助功能」权限。ad-hoc 更新可能使既有授权失效；如无法读取输入框，在「系统设置 → 隐私与安全性 → 辅助功能」检查并按系统提示重新授权。

发行包只有本地 **ad-hoc 签名，没有 Developer ID 签名或 Apple 公证**。若 macOS 无法验证开发者，核对下载来源后，在「系统设置 → 隐私与安全性」按系统提示选择「仍要打开」；不要关闭系统整体安全保护。

## 验证与兼容边界

本版变化依据 `v0.3.0..8b2cf74` 的实际差异；发行构建源码 `f640848`（0.4.0/build 5 版本提交）。全量 `swift test` 退出码 0：346 项、1 项联网探测默认跳过、0 项失败；覆盖浮窗命中区、译文拖选复制、坐标换算、模型密钥本机存储与旧钥匙串导入路径，以及既有输入、服务和浮窗回归。

本版本 DMG 构建、`hdiutil verify`、只读挂载内容检查及严格 ad-hoc 验签通过；镜像内应用为 0.4.0/build 5、arm64，Info.plist 与 Mach-O 最低系统版本均为 macOS 15.0，Bundle ID 保持 `com.comeg.runwu`。应用内文件与打包输入逐字节一致，LICENSE 与仓库一致，Applications 链接指向 `/Applications`，核验后已卸载镜像。英文发行文件与本地中文文件同字节，历史 0.1.0/0.2.0/0.3.0 本地 DMG 保持。本次发行包核验未安装或启动生产应用，也未下载苹果语言包。

已知边界：一次拖选不跨 Markdown 段落；非激活窗口的选区为系统浅灰色；密钥以明文保存在本机偏好文件里，同一用户下的其它进程可以读取，这是本版按需求做出的取舍；旧钥匙串条目不会被自动读取或删除，需要时用「导入旧版钥匙串密钥」。真实宿主焦点、苹果原生翻译 session 与语言包、用户自定义模型端点仍需实际使用验证。
