# 润物 v0.2.0

v0.2.0（内部构建号 3）包含浮窗服务切换、输入资格检查、长卡缩放与设置窗口 Dock 生命周期更新。支持 **Apple Silicon（arm64）、macOS 15 或更高版本**；应用身份保持「润物」与 `com.comeg.runwu`。

## 本版变化

- **浮窗显示译文来源并切换服务**：头部显示生成当前译文的服务，可选择苹果本地翻译、大语言模型 API、Google、Bing 或有道。选择保存为全局服务，并立即使用所选卡片保存的原文和语言方向重译；后续翻译使用新服务，其他钉住卡仍保留原译文及服务标签。大语言模型 API 标签表示服务类别，不表示实际模型名称。
- **重译状态与原文边界**：重译不重新读取输入框或剪贴板，也不自动复制或替换输入。加载时显示目标服务，旧结果保留来源；失败时保留旧译文并显示提示，全局选择仍保存。菜单展开及重译期间暂停该卡自动隐藏，结束后恢复原策略。钉住、拖动位置保持；位置预览没有原文，不提供重译菜单。
- **输入资格检查**：读取正文前校验焦点和编辑资格，拒绝明确只读、禁用的控件及未聚焦的列表文本；搜索、重命名等输入框继续支持。Finder 式目录列表已通过合成回归。缺少可选编辑元数据的原焦点标准原生文本控件仍保持兼容，不能保证识别所有未标明只读的宿主；真实 Finder 输入树及实机点击尚未核验。分句继续按光标位置和既有标点规则，不新增“必须键入才翻译”的条件。
- **长卡缩放修复**：加载或失败状态下，手动缩放使用包含状态行的实际卡片高度预算，保持正文滚动区域和窗口尺寸一致，避免状态行少计造成布局偏差。
- **设置窗口与 Dock**：启动仅显示菜单栏，打开设置时显示 Dock，关闭最后一个设置窗口后隐藏 Dock；翻译卡、欢迎或授权提示不使 Dock 常驻。菜单栏入口的设置窗口最小化后保留 Dock，再打开设置或点击 Dock 可恢复原窗口。SwiftUI 设置入口保留系统固有能力，不新增最小化支持；用户手工固定的 Dock 项不由应用删除。

## 安装与更新

1. 从 [v0.2.0 发行页](https://github.com/cmeng-CM/Runwu/releases/tag/v0.2.0) 下载 `Runwu-0.2.0.dmg`。
2. 更新旧版时先从润物菜单栏退出应用。打开 DMG，将「润物.app」拖到「Applications」链接；已有旧版时选择替换。
3. 推出镜像，再从应用程序目录启动润物。润物目前没有自动更新。
4. 首次运行按系统提示授予「辅助功能」权限。ad-hoc 更新可能使既有授权失效；如无法读取输入框，在「系统设置 → 隐私与安全性 → 辅助功能」检查并按系统提示重新授权。

应用只有本地 **ad-hoc 签名，没有 Developer ID 签名或 Apple 公证**。若 macOS 无法验证开发者，核对下载来源后，在「系统设置 → 隐私与安全性」按系统提示选择「仍要打开」；不要关闭系统整体安全保护。

## 验证与兼容边界

本版全量 `swift test` 共 278 项，1 项联网探测默认跳过，0 项失败。使用隔离服务、临时配置、合成辅助功能数据及原生窗口回归验证；覆盖服务菜单、请求失效、输入资格、加载/失败长卡缩放和设置窗口生命周期。官方 DMG 构建、镜像校验及严格 ad-hoc 验签通过；只读挂载核实内部版本为 0.2.0/build 3、arm64/macOS 15.0，应用与本地构建逐文件字节一致，Applications 链接指向 `/Applications`，随后已卸载镜像。未读取真实用户输入或密钥，未安装或启动生产应用，未下载苹果语言包。

真实宿主焦点、苹果原生翻译 session 与语言包、用户自定义模型端点仍需实际使用验证。辅助功能与光标几何取决于宿主实现，不保证所有应用兼容；遇到限制可使用排除设置、固定位置或剪贴板翻译。网页服务需要网络，可能限流或改变协议。

历史 v0.1.0 发行附件保持原内容。操作与服务配置详见 [使用手册](https://github.com/cmeng-CM/Runwu/blob/v0.2.0/README.md)。
