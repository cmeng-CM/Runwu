# 润物 v0.3.0

v0.3.0（内部构建号 4）改进浮窗避让、Obsidian 当前句定位与行尾映射，修复有道网页翻译握手，并增加输入链路诊断及本机开发固定签名支持。支持 **Apple Silicon（arm64）、macOS 15 或更高版本**；应用身份保持「润物」与 `com.comeg.runwu`。

## 本版变化

- **光标跟随与输入框避让**：未钉住的活动实时卡优先放在输入框与光标框的并集之外，先试上方或下方，再试光标行左右；中线附近的轻移减少翻面。没有干净位置时选择重叠较少的回退位置，仍可能压住输入框。宿主把整个编辑器报成输入框时，高度超过所在屏 0.6 倍的矩形不再作为跟随避让障碍，优先贴光标行；可能压住正文其它行。焦点元素没有输入框矩形时，在已有读取预算内尝试有限祖先兜底。
- **固定卡组避让与高度修复**：关闭跟随后，同屏自动摆位卡按整组让开输入框，输入框移开后回到配置槽位；整组放不下时保留原槽位，仍可能重叠。剪贴板卡使用固定布局，可随同屏自动卡组一起挪位；钉住或手动拖动的卡保持原有位置策略。面板高度取实测渲染与文本预算的较大值，修复长译文高度低估、内容可能画出面板的问题。
- **Obsidian 宿主偏移映射**：针对 Chromium contenteditable 的宿主偏移与 `AXValue` 文本两套坐标系，先读取光标前锚窗，映射到 AXValue 的 UTF-16 边界后取句。逐字匹配优先；找不到时容忍空格、换行、制表与零宽标记的表示差异。匹配仍保留短锚门槛、方向守卫和光标后一位字符甄别；锚窗读取失败、匹配或甄别不过时拒绝该内容采样。宿主不支持锚窗读取或锚窗太短时沿用报告偏移，不能保证这类宿主定位正确。
- **文字行尾后空行修复**：归一化锚窗以实义字符结束时，光标还原到最后匹配 UTF-16 单元之后，避免跨过后续空行而取到空句；前移一字时映射也只前移一字。新增回归覆盖连续空行、文末、emoji/组合字符与方向防护。锚窗以空白或零宽标记结束时保留旧边界策略，不推断空白行归属。
- **有道网页翻译握手修复**：先获取匿名网页会话 cookie，再完成签名握手并发送完整句子；补全请求字段。已有会话复用，code50 拒绝时重取会话并最多重试一次；取不到 cookie 或重试仍失败时报告错误。源语言仍由有道自动识别，应用中的源语言设置用于本地输入筛选；网页服务仍依赖网络与上游协议。
- **无正文输入诊断**：诊断报告和可选日志增加组合状态、UTF-16 长度、报告/映射选区、会话与固定失败原因，区分采样失效/恢复、防抖排队/取消/到期、空取句和句子去重。新增输入诊断不记录正文、锚窗、译文或密钥，重复失败按状态转移记录；诊断本身不改变默认 450ms 防抖、翻译条件或读取预算。缺失字段和粗分类原因不能据此推断用户实际输入状态。
- **本机开发固定签名支持**：新增 `Scripts/setup-signing.sh` 配置本机 Runwu Local 自签身份；`Scripts/build-app.sh` 自动选择已有身份，也可显式指定身份，缺少身份时退回 ad-hoc。复用同一证书和 Bundle ID 可保持稳定指定要求，减少因重建哈希变化触发的辅助功能重新授权；更换证书（包括重建同名证书）仍会改变身份。配置脚本会导入证书、设置用户域代码签名信任并保存私钥备份，应用构建脚本只读取身份。此支持用于本机开发，**标准 DMG 仍强制 ad-hoc 签名，没有 Developer ID 或 Apple 公证**。

## 安装与更新

1. 从 [v0.3.0 发行页](https://github.com/cmeng-CM/Runwu/releases/tag/v0.3.0) 下载 `Runwu-0.3.0.dmg`。
2. 更新旧版时先从润物菜单栏退出应用。打开 DMG，将「润物.app」拖到「Applications」链接；已有旧版时选择替换。
3. 推出镜像，再从应用程序目录启动润物。润物目前没有自动更新。
4. 首次运行按系统提示授予「辅助功能」权限。ad-hoc 更新可能使既有授权失效；如无法读取输入框，在「系统设置 → 隐私与安全性 → 辅助功能」检查并按系统提示重新授权。

发行包只有本地 **ad-hoc 签名，没有 Developer ID 签名或 Apple 公证**。若 macOS 无法验证开发者，核对下载来源后，在「系统设置 → 隐私与安全性」按系统提示选择「仍要打开」；不要关闭系统整体安全保护。本机开发固定签名不会改变下载 DMG 的签名政策。

## 验证与兼容边界

本版变化依据 `v0.2.0..9c07dbe` 的完整实际差异。v0.3.0/build 4 构建源码 `bf633ac` 已通过全量 `swift test`，退出码 0：336 项、1 项联网探测默认跳过、0 项失败；覆盖输入会话与组合状态、映射/行尾/UTF-16 边界、诊断隐私哨兵、浮窗避让和渲染、有道会话与重试。

本版本 DMG 构建、`hdiutil verify`、只读挂载内容检查及严格 ad-hoc 验签通过；镜像内应用为 0.3.0/build 4、arm64，Info.plist 与 Mach-O 最低系统版本均为 macOS 15.0，Bundle ID 保持 `com.comeg.runwu`。应用内全部 7 个文件与打包输入逐字节一致，LICENSE 与仓库一致，Applications 链接指向 `/Applications`，核验后已卸载镜像。英文发行文件与本地中文文件同字节，历史 0.1.0/0.2.0 本地 DMG 保持。本次发行包核验未安装或启动生产应用，也未下载苹果语言包。

用户 2026-10-14 回复「测试了，没问题，收尾打包安装吧」，确认此次 Obsidian 输入与行尾浮窗问题复验通过。该反馈不代表全部宿主、全部输入或布局场景通过。

辅助功能文本与几何依赖宿主。重复锚或重复行且后一位字符相同时，首个匹配仍可能错配；偏移映射正确时「替换原文」按对应范围替换或被既有门槛拒绝，不能把映射发生等同于所有重复行均正确。未映射时沿用报告偏移，仍可能取错句或错行替换；锚尾为空白/零宽标记时仍有跨空白块的残余边界。

旧 `caret-offset-mapping` T5（无可信光标框且只剩被丢弃的整屏输入框时暂隐）尚未实施；该情况下仍可能按旧兜底摆放卡片。其它几何报偏、空间不足或读取受限场景不保证完整避让。真实 Finder 输入树、苹果原生翻译 session 与语言包、用户自定义模型端点仍需实际使用验证；网页服务可能限流或变更协议。遇到宿主限制可使用排除设置、固定位置或剪贴板翻译。

历史 v0.1.0/v0.2.0 发行说明、标签和附件保持。使用方式详见 [使用手册](https://github.com/cmeng-CM/Runwu/blob/v0.3.0/README.md)，定位与诊断边界见 [行尾映射设计](https://github.com/cmeng-CM/Runwu/blob/v0.3.0/docs/designs/obsidian-line-end-mapping.md) 和 [输入链路诊断](https://github.com/cmeng-CM/Runwu/blob/v0.3.0/docs/designs/obsidian-input-diagnostics.md)。
